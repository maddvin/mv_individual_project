# Individual project 

This is the repository containing all files and code (presented as .ipynb notebook) for my individual project. 

The code and files uses RNAseq data and genomic.gff to define a provisional dormancy signature from E. coli. 

Packages required for the code to run are: 
- pandas
- numpy
- matplotlib.pyplot
- seaborn

The csv and .gff files are uploaded in the github repository and are read in using pandas 

Project overview:
My PhD aims to look at the molecular mechanisms underlying stem cell dormancy, which is critical for understanding disease and development processes. Much of the foundational knowledge for this project comes from structural and molecular findings in stationary phase bacteria, particularly E. Coli, which are thought to represent dormant bacterial populations in many real-world biological contexts. Therefore, this individual project aims to define a provisional dormancy signature, using RNA-seq data from E. Coli cultures in exponential and stationary phases and identifying genes with significant differential expression between the two.
